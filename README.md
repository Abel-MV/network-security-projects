# Network Security Projects

A collection of hands-on network security projects developed as part of my BSc Cyber Security studies and independent learning.

These projects focus on understanding network communication, analysing traffic, identifying exposed services and testing security controls in practical lab environments.

## Projects

### 1. [Network Reconnaissance & Service Enumeration](network-reconnaissance/README.md)

Network discovery and service enumeration using Kali Linux, Ubuntu Server and VMware Workstation Pro.

**Key topics:** Nmap, TCP port states, SSH, HTTP, service detection and UFW firewall rules.

**Status:** Completed — Published.

### 2. Network Traffic Analysis

Practical investigation of network traffic and protocol behaviour in a controlled lab environment.

**Status:** Completed — documentation pending publication.

### 3. Network Firewall & Traffic Filtering

Configuration and validation of network filtering rules to understand how firewalls control access to network services.

**Status:** Completed — documentation pending publication.

## Lab Approach

Each project follows a practical process:

1. Define the objectives and lab environment.
2. Configure the required systems and tools.
3. Execute and document the tests.
4. Analyse the results and security implications.
5. Record findings, limitations and lessons learned.

All testing is performed in authorised lab environments.

## Documentation

Each published project will include its own README with the environment, methodology, relevant commands, findings and selected technical evidence.
